# Vite & React Rules
* **Tech Stack:** Vite + React 19 + TypeScript.
* **Component Naming:** PascalCase for React components (`Component.tsx`), kebab-case for utilities (`utils.ts`).
* **Rendering:** Use vector glyphs instead of raster images.
* **PWA:** Service worker ensures offline-first caching via Cloudflare.
