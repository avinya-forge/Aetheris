# Product Rules
* **Backlog:** Append-only ledger in `docs/planning/backlog.md`.
* **Format:** Statuses: `[x]` done · `[ ]` pending · `[READY]` next up.
* **Focus:** Zero-cost deployment (Free-tier alignment).
* **Release:** Update `release-notes.md` on every sprint completion.
