## 1. Vision Statement
To eliminate "Information Fatigue" by replacing sensationalist news feeds with a **Temporal Intelligence Engine**. Aetheris traverses time—from the past 2 hours to the next 2 days—using high-integrity, primary-source data to predict cascading impacts on safety, environment, and society.

## 2. Getting Started
To initialize the environment and sync documentation:
```bash
bash script/run.sh --start
```

To run tests:
```bash
bash script/run.sh --test
```

To view current status:
```bash
bash script/run.sh --status
```
